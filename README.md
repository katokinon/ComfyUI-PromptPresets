# 提示词预设（ComfyUI Prompt Presets）

给 ComfyUI 的每个提示词输入框加一个小按钮。点开就是**这个节点最近用过的提示词**和**整理好的预设库**，点一下直接填进文本框。

不用来回复制粘贴，也不用在文件夹里翻找上次写的那段话。

## 功能

- **历史提示词**：任务执行成功后自动记下用过的提示词，每个文本框保留最近 10 条，重复的会提到最前面
- **随手翻历史**：文本框边上 `‹` `›` 两个按钮，不开面板就能切上一条 / 下一条
- **预设提示词**：把满意的整段提示词存下来，数量不限
- **按工作流整理**：预设自动归到当前工作流名下
- **跨工作流调用**：下拉切一下，就能用其他工作流里存的预设
- **一键互转**：历史里那条点「存为」，改个名字就变成预设
- **搜索**：历史和预设一起过滤，存多了也找得到
- **只看标题**：预设多了可以关掉正文预览，一屏扫过更多条
- **记住浏览状态**：上次停在哪个页、看哪个工作流的预设、要不要正文，下次打开照旧
- **两种渲染都支持**：传统画布和 Nodes 2.0（Vue 渲染）都能用

## 安装

把 `ComfyUI-PromptPresets` 文件夹放进：

```
ComfyUI/custom_nodes/ComfyUI-PromptPresets/
```

重启 ComfyUI，不需要安装任何依赖。

插件不会往节点菜单里加东西，也不改动工作流结构。

## 使用

### 按钮在哪

鼠标移到任意多行提示词输入框的**左下角**，会看到一组小按钮。CLIP 文本编码、各类文本节点都有。

| 按钮 | 作用 |
|---|---|
| `P` | 打开面板（历史 / 预设） |
| `‹` | 上一条历史提示词（更早用过的） |
| `›` | 下一条历史提示词（更新的） |

连着点 `‹` 就能把之前用过的提示词一条条翻出来，不用开面板。翻到头会绕回另一头，不会卡住。

### 面板里有什么

面板分成**历史**和**预设**两个选项卡，点标题切换，顶部的搜索框同时过滤两边。

| 位置 | 内容 |
|---|---|
| 顶部 | 搜索框 |
| 选项卡 | 历史（条数）、预设（条数） |
| 历史页 | 本节点用过的提示词，右上角显示 `3/10` 和「清空」；每行右边有「存为」 |
| 预设页 | 预设列表，右上角下拉可切换「当前工作流 / 全部工作流 / 某个工作流」，旁边有「详细」开关；每行右边有「删」 |
| 底部 | 「把当前内容存为预设」—— 把文本框里现有的整段存下来 |

### 几个常用动作

- **快速回看上次写的**：点文本框边上的 `‹`，一次一条
- **复用历史里某一条**：`P` 打开面板，「历史」页点那条，内容立刻写回文本框
- **把满意的存下来**：历史那条右边的「存为」，名字默认取首行，改一下回车即可
- **存正在写的这段**：面板底部按钮
- **用别的工作流里的预设**：`P` → 「预设」页 → 下拉切到「全部工作流」，每行会标出来源
- **删掉不想要的预设**：每行右边的「删」，会再确认一次
- **预设太多翻着累**：在「预设」页取消勾选「详细」，列表只留标题，一屏能扫过十几条

点完一条下拉不会关，方便连着试几条；点面板外面就收起。

## 数据存放

```
ComfyUI/user/prompt_presets/data.json
ComfyUI/user/prompt_presets/data.json.bak
```

- 放在 user 目录里，插件升级或重装都不会丢
- **不写进工作流文件**，把工作流分享给别人不会带上你的预设
- 纯本地文件，不联网
- 换机器或备份：直接拷这个文件夹

## 常见问题

**按钮没出现？**

- 确认插件在 `custom_nodes` 下并且重启过 ComfyUI
- 节点处于折叠状态时不显示按钮，展开就好
- 切换过 Nodes 2.0 开关的话，刷新一次页面

**历史一直是空的？**

历史只在任务**执行成功后**记录。改完文本但没有跑，不会进历史。

**复制节点后历史不跟着走？**

历史是跟着节点记的，复制出来的新节点算新的一格。预设不受影响——预设是按工作流存的。

**为什么有「未保存的工作流」？**

还没保存过的新工作流，预设会先记在这个临时分类下，避免和已有的流混在一起。保存之后新存的内容会归到正式的工作流里。

**预设会跨工作流串味吗？**

不会。默认只显示当前工作流的预设，要用别的得自己在下拉里切。
